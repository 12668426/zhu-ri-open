# 教程⑥：MacBook 屏幕自动适配

逐日不是只针对单一 MacBook 型号设计的。与其识别设备名称，网页更关注**实际可用的 CSS 像素宽度**：同一台 MacBook 在显示缩放、窗口尺寸或右侧留白调整后，可用宽度也会变化。

## 已实现的自动布局规则

- **宽屏**：左右两栏，时钟与倒计时在左，时间表在右，字体和表格间距适当放大。
- **中等宽度**：左右栏保留但缩小内间距，倒计时字体缩放，六列表格压缩字号而非溢出。
- **较窄的桌面面板**：不再硬挤成两栏，改用上下布局，卡片内容仍可纵向滚动。
- **窗口或屏幕本身很窄**：全宽排列，不显示留白拖动条；手机浏览器只能作为兼容访问，不承诺完整桌面体验。
- **不同高度**：低高度屏幕会减少顶部空白、时钟体积和卡片内边距，尽量保留时间表可视区域。

这组规则以 `src/adaptive.css` 的 **CSS Container Queries** 为核心：它根据面板的可用宽度作出响应，而非通过 `MacBook Neo/Air/Pro` 这种设备名分支。绝大多数现代 Safari/macOS 支持容器查询。

## 支持目标（不是全部设备实测承诺）

| 设备举例 | 常见变化 | 自动适配策略 |
|---|---|---|
| MacBook Neo 13英寸 | 中等桌面宽度、右侧需要文件留白 | 双栏优先，宽度不够自动压缩/重排 |
| MacBook Air 13/15英寸 | 显示缩放、不同可用宽度 | 根据当前 CSS 宽度响应 |
| MacBook Pro 14/16英寸 | 屏幕较宽、密度较高 | 更宽卡片与更大字号 |
| 外接显示器、Mac mini、iMac | 显示器大小不固定 | 根据真实窗口宽度响应 |
| 浏览器非全屏 / 放大网页 | 可用宽度缩小 | 在阈值处自动改为上下排列 |

**注意：** 以上是兼容目标，并不代表在所有 MacBook、macOS 版本、显示缩放、Plash 版本上都已真机逐一验证。遇到布局问题可以提交 issue，并附分辨率、缩放、macOS 与 Plash 版本。

## 怎么验证自己的屏幕？

1. 打开逐日，正常查看时钟、完整时间表、底部信息。
2. 在 Plash 的 Browsing Mode 中尝试把留白胶囊左右拖动，观察时间表能否自动调整。
3. 如果你改了 macOS 显示缩放，刷新 Plash 后检查布局。
4. 深色/亮色切换通过系统设置完成，颜色会自动跟随。
5. 只要出现水平滚动或文字被截断，就属于应报告的适配问题；不是用户必须接受的限制。

## 开发者测试建议

至少通过浏览器自动化测试以下视口：`1024×768`、`1280×800`、`1440×900`、`1512×982`、`1728×1117`、`1920×1080`，并测试多档留白比例及系统深/浅色。自动化截图不能替代真实 Mac 上的 Plash 功能验收。
