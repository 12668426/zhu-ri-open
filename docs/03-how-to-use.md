# 教程③：从第一张桌面壁纸到日常交互（不懂代码也能上手）

## 1. 第一次打开

第一次在浏览器或 Plash 打开逐日壁纸时，会看到「开始使用逐日」的说明。选择：

- **空白计划**：一张没有任何安排的时间表，适合认真从头建立自己的习惯。
- **通用示例**：展示几段通用日程，你可以直接编辑、替换或清空。

不用登录或付费。

## 2. 添加自己的时间表

1. 在右侧卡片「每日时间表」点 **调整日程**。
2. 点 **添加时段**，例如开始 `09:00`、结束 `10:00`。
3. 在「安排」填写比如 `专注写报告`，类别可选择专注/休息/生活/运动/睡眠。
4. 在「科目/项目」选择或填写对应项目（没有项目也可以先只写安排）。
5. 勾选本时段重复的星期，例如周一～周五；周末可以另设时段。
6. 点 **保存**。时间表会自动计算时长并按照开始时间排列。

**时长无需手填**：不足1小时显示分钟；超过1小时会自动组合小时和分钟。注意开始、结束均为24小时制。跨午夜可以输入例如 `23:00` 到 `07:00`，表示次日07:00结束。

## 3. 创建项目/阶段/任务

举例：你想安排一个「每周读书」计划。

1. 在左侧点击 **查看全部**，打开右侧卡片的「我的计划」。
2. 点 **新建计划**，输入 `每周读书` 并保存。
3. 进入这个计划，点 **添加阶段**，例如 `第一周`。
4. 进入阶段，点 **新增任务**，输入 `完成第1章`、`做阅读笔记` 等。
5. 每完成一项，点任务前的方框打卡；再次点击可取消打卡。
6. 点击卡片顶部的 **←** 可以返回上一级，不会打开新网页。

计划完成进度来自任务勾选，不代表当前时间段走过的比例。

## 4. 把时间段和项目关联

进入 **调整日程 → 编辑某个时间段**，关联你建立的项目。以后点击时间表中的这行，可以从同一张卡片进入对应项目内容。其他卡片（时钟、倒计时）保持不动。

## 5. 正在进行的倒计时怎么理解？

- 当前安排的开始时间 ≤ 电脑当前时间 < 结束时间，系统将其标记为正在进行。
- **大数字**是距离本时段结束的剩余时间，按秒更新。
- **进度条**是时段已过去的百分比，不等于任务完成度。
- 「接下来」显示系统找到的下一条时间安排。
- **时间到了不会自动帮你给任务打勾**，任务是否完成由你决定。
- 不在任何计划时段里，卡片会显示当前空闲状态或下一项安排。

请确认 Mac 的系统日期、时区和时间设置正确。

## 6. 桌面留白胶囊有什么用？

留白用于放 Finder 文件图标。壁纸内容区域的右边有一根**细竖线**：

- 拖动到左侧：学习区域变窄、右侧文件留白更大。
- 拖动到右侧：学习区域更宽，最右边可让留白接近0。
- 双击：恢复默认留白大小。
- 键盘焦点在胶囊上时，方向键微调。

若你的屏幕分辨率较低，系统会自动限制最大留白，避免重要卡片被完全挤没。屏幕适配详情见 [教程⑥](06-screen-support.md)。

## 7. 深色与浅色

逐日默认跟随 Mac：**系统设置 → 外观 → 自动 / 浅色 / 深色**。不需要在网页里找切换按钮。如果 macOS 正在自动切换，页面会随系统改变。

## 8. 时间表会自动滚到哪一行？

逐日打开或返回时间表时，会自动在**右侧时间表卡片内部**定位到当前正在进行的安排；没有正在进行的安排时，定位到今天下一项，今天安排全部结束后定位到最后一项。进入下一个时间段时，时间表也会自动移动。**查看时间表不需要开启 Plash 浏览模式。**如果你主动滚动查看其他行，系统不会每秒抢回位置；等时间段改变时再自动定位。

## 9. 怎么直接操作桌面壁纸？

普通模式用于看桌面，不影响 Finder 文件操作。要点击表格、打卡或调整卡片时，先在 Plash 菜单启用 **Browsing Mode**；操作完成后关闭它。网页不提供系统通知，也不会替代你日历中的提醒。
