# 教程⑤：数据备份、迁移与隐私

## 数据存在什么地方？

逐日默认把数据保存在当前网页来源的 `localStorage` 中，键名是 `zhuri-open-v1`。它不需要账号，也不会把用户数据上传给开源仓库作者；没有内建广告、追踪或同步服务。

⚠️ `localStorage` 不是保险箱：清理浏览器网站数据、换电脑、换网址、Plash 和 Safari 使用不同存储空间，都会导致看不到原来的记录。不要把唯一副本只放在浏览器里。

## 最简单的备份（建议每周一次）

1. 打开平时真正用于学习/工作的那一个逐日页面（如 Plash，先开启 Browsing Mode）。
2. 在右侧时间表卡片点击 **调整日程**。
3. 向下找到 **数据管理 → 导出 JSON 备份**。
4. 网页会生成一个 `.json` 文件，建议保存到你能记住的位置（例如「文稿/逐日备份」）。
5. 给备份文件保留日期，例如 `zhuri-backup-2026-10-08.json`，不要随意发到公开论坛。

## 导入恢复（导入前要确认）

1. 在新的浏览器或电脑里打开逐日，进入 **调整日程 → 导入 JSON 备份**。
2. 选择以前保存的 `.json` 文件。
3. 系统会提示「导入将覆盖当前计划」，确认你已经备份现有数据，再点击确认。
4. 等待页面更新；检查时间表和任务列表是否正确。

**导入目前是覆盖，不是智能合并。** 建议不要同时在 Safari 与 Plash 各改一份数据后期待它们自动合并。

## 公开开源仓库需要注意什么？

- 公开仓库只应该包含**通用代码和示例数据**。
- 不要把含电话号码、课表、学校、住址、私人备忘、私人任务的 JSON 备份上传到 GitHub。
- 逐日开源版初次启动不会包含作者专属数据，也没有自动读取个人版计划的功能。
- 若以后引入第三方服务、云同步，必须更新隐私说明；当前版本不具备云同步。

## 是否能离线备份？

可以。JSON 是在浏览器本地生成的文件，不依赖远端服务器。请自己妥善保存、定期复制到其他设备或存储盘。
